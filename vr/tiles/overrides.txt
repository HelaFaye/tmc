# Tile overrides: what a cell is, where tileid's guess from the drawing is
# wrong, and heights the drawing cannot tell. Read by tools/tileid.py
# (families) and tools/tilevox.py (heights, set after every other stage).
# Coordinates and tile type numbers only -- nothing from the ROM.
#
# Find a cell's coordinates with tools/tile_review.py DUMPS AA_RR.
#
#   AA_RR x,y              one cell of room AA_RR
#   AA_RR x0,y0-x1,y1      a rectangle, inclusive
#   AA_RR type=0xNNN       every cell of that tile type in the room
#   aN    type=0xNNN       ... in area N
#   aN    tile=0xNNN,0xMMM every cell drawn with those metatiles, in area N
#                          (type 0x70 alone is fences, rocks and cliffs)
#   *     type=0xNNN       ... in the whole game
#   *     special=0x4NNN   every cell of an object tile (Picori's SpecialTile)
#
# followed by family=NAME (bush sapling rock mushroom stump planter pot prop
# spiky_rock boulder stone signpost fence foliage flowers, or - for none), height=PX, and/or
# label=NAME (a name for people, no spaces; it shapes nothing).
#
# Picori's own names seed the families before any of this (tools/
# picori_labels.py): CUT_BUSH, ROCK, PERMA_ROCK, SIGNPOST, Pots, Boulder.
# tools/tile_labeler.py edits this file from a browser.
